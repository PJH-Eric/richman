# 寶島大富翁

可愛風格的 **3D 大富翁**：**每一局的地圖都是隨機生成的**（主題、地名、色組、特殊格位置都不同），只要選格數（48／64／80／96／120 格）；單機 1～5 隻電腦（6 人上限）、線上房間、觀戰、邀請連結、道具；伺服器零依賴。
單機可跟四種難度的電腦玩，也可以開線上房間跟朋友玩、邀請觀戰。平板觸控優先，手機、桌機都能玩。

- 前端：純 HTML／CSS／JavaScript，3D 使用 [three.js](https://threejs.org/)（MIT，精簡版已放在 `public/vendor/three.min.js`），直接開啟即可執行
- 伺服器：Node.js（>= 22），**零第三方依賴**（自己實作 WebSocket），房間只存在記憶體
- 規則與電腦共用同一份程式（`public/js/rules.js`、`ai.js`），單機與線上使用同一套規則

## 快速開始

```bash
node server.js          # 或 npm start
# 打開 http://localhost:3100
```

Windows 可以直接按兩下 `啟動遊戲.bat`。只玩單機時可省略伺服器；three.js 以 ES 模組載入，請用 `http://` 開啟。

> 需要瀏覽器支援 **WebGL**（近幾年的手機、平板、電腦瀏覽器都有）。缺少 WebGL 時會顯示說明文字。

## 玩法摘要

- **地圖**（單機開局時選格數、線上由房主在房間設定選）：48／64／80／96／120 格。每局依「格數＋種子」隨機生成，主題（寶島、世界旅行、遊樂園、海底、太空）、地名、色組與特殊格位置都不同；地圖代號（如 `g64-xxxx`）存在對局裡，前後端各自重建出同一張。
- **道具商店與道具點數**：每張地圖都有 2 間以上「道具商店」（約每 24 格 1 間、全圖最多 4 間、每一邊最多 1 間；機會／命運格也比先前少）。購買要用「道具點數」（開局＝回合上限×10，不限回合 500 點；機會／命運卡也可能送點數）。每次停到商店隨機上架 3～6 樣，同一次每樣只能買 1 件（再走一圈踩到算新的一次）；庫存整場全房共用、越貴越少；道具 10～100 點，共 24 種；也可以把身上的道具**半價賣回商店**。每人最多帶 10 個。大廳／首頁有「道具說明」可查全部道具。
- 最多 **6 人**（單機 1 真人＋最多 5 電腦，線上房間固定最多 6 人），起始現金＝回合上限（不限回合當 100）×200×地圖倍率（48／64／80／96／120 格＝×1.2／1.4／1.6／1.8／2；例如 25 回合 80 格＝8000，不限回合 120 格＝40000），起點薪水＝500×同一倍率（600／700／800／900／1000）
- **金額隨初始資產調整**：資產倍率＝起始現金÷6000（限制 1～4，最低為 1；例如 40 回合 64 格＝1.87、25 回合 48 格＝1、不限回合的大圖最高 4）。地價、房價、過路費、稅金、車站／公司租金、機會／命運卡的金額、財神／衰神、出獄罰金都乘上它（收錢卡、財神再額外 ×1.5；起點薪水只看地圖大小；經典 40 格維持原價），初始資產越高花費越高、越低越低
- 每次擲骰前先選「1 顆」或「2 顆」骰子（1 顆走 1～6、2 顆走 2～12）；點數會先停一下讓你看清楚才走，停在空地可以買；踩到別人的地要付過路費
- **房產升級**：每塊地都能單獨一路升到旅店（4 棟房再升旅店），每塊地獨立升級；買齊整組另有空地租金加倍與連棟加成；棋盤上的地主標示有動物頭像、旗子與顏色框
- 停在「機會」「命運」抽卡；監獄可提早繳罰款（依個人總資產：10%，最少 50、最多 500）、用出獄許可證離開，或待滿 3 回合免罰金出獄；在牢裡只能待著或繳罰款，待滿整整 3 個回合出獄，第 4 回合起才擲骰
- **連棟加總**：同一人在相鄰的連續格子都蓋了房子時，踩到其中任何一格，要付的是整串每一格過路費的總和再打 8 折（空地、機會／命運／車站等會把串斷開）；每塊地最多加蓋 5 次（第 5 次是旅店）；面板上隨時都有「我的地產」按鈕可看清單
- **蓋房只能在走到自己的地時**，且每次停留只能蓋一棟（當下踩到的那塊），由面板詢問是否加蓋；欠錢時可以賣房子救急
- **命運之神**：抽到卡片可能被福神、財神、窮神、衰神附身 4 個回合
- 每場開局地價、房價、租金、稅金都會在原價 ±30% 內隨機，全部是整數
- **道具**（最多帶 10 個，面板上的「道具庫」可以看全部道具、說明並直接使用）：停在休息站、道具商店，或抽到道具卡取得。主動道具（擲骰前用，共 16 種）：「遙控骰」自己選走 1～12 步、「偷錢卡」（偷 10% 現金，有上限）、「搶奪卡」（隨機搶走對手 1 個道具）、「換位卡」、「冰凍卡」（對手跳過下一回合）、「陷害卡」（對手直接坐牢）、「均富卡」（和對手現金平分，100 點）、「炸彈」、「加蓋券」（自己的地免費蓋一間）、「漲價卡」（自己一塊地過路費 ×1.5、持續 3 個回合）、「收租券」（向每位對手各收一筆錢）、「加骰券」（這回合走完可以再擲一次）、「福袋」（隨機得到 1 個道具）、「領薪券」（立刻領一次起點薪水）、「求神符」、「驅神符」；被動道具（時機到自動生效，共 8 種）：「免租券」「反彈卡」（免付過路費、屋主反而付你一半）「強制購地券」（付完過路費後這塊地變成你的）「購地免費券」「招財貓」「起點加碼券」「保釋券」「護身符」（擋下偷錢／搶奪／換位／冰凍／陷害／炸彈／均富）
- 勝負：其他人都破產，最後存活的人獲勝；也可以設回合上限（25／40／50 回合，或無上限），時間到比總資產
- 電腦難度：幼幼班（亂玩、專心走路）、簡單、普通、困難（會搶整組、算過路費風險、聰明地用道具）
- 音效全部現場合成：買地、收付租金、稅金、好／壞機會命運、被攻擊、偷錢、換位、炸彈、護身符、神明附身、撿道具、蓋旅店、加入房間、錯誤提示等各有聲音
- 所有可捲動的畫面都用自製圓潤卷軸（`public/js/scrollbar.js`），可拖曳、永遠看得到
- 顏色以外還有形狀（圓、方、三角、菱形）區分玩家，色盲也看得出來

## 操作

- 點棋盤上的格子看說明；單指或滑鼠左鍵拖曳＝平移視角（滑鼠右鍵或 Shift＋拖曳、雙指扭轉＝旋轉；雙指／滾輪縮放；雙擊或「轉正」回正）；右下角按鈕切換「跟著棋子／看全圖」
- 空白鍵或 Enter：擲骰、買地、結束回合；Esc：開選單或關視窗
- 右上角齒輪：背景音樂／音效（各自音量）、震動、減少動態、加快動畫、大字，設定會存在這台裝置

## 環境變數

複製 `.env.example` 參考（環境變數請由平台或 shell 設定）：

| 變數 | 用途 | 預設 |
| --- | --- | --- |
| `PORT` | 伺服器埠號 | `3100` |
| `GAME_SERVER_URL` | 前端要連的遊戲伺服器（僅在前端與伺服器分開部署時使用，建置時注入） | 同源 |
| `GAME_ALLOWED_ORIGIN` | 允許連線的前端來源（正式環境請填前端網址，例如 `https://<帳號>.github.io`） | `*` |

前端只從 `public/js/config.js` 這一個模組讀取伺服器位置，網址設定集中在這個模組。

## 測試

```bash
npm test               # 規則單元測試＋電腦互打 100 局（純規則測試）
npm run test:item-cases # 24 種道具＋商店＋道具欄上限的專屬規則案例（每個參數邊界、護身符互動、新道具各自的效果），幾秒跑完
npm run test:e2e-quick # 平行跑最重要的實機測試（瀏覽器主流程＋道具流程＋線上道具），約 5 分鐘
npm run test:e2e       # 平行跑全部實機測試（含捲動直／橫向、卡死掃描、地圖）；--jobs=N 調平行度、--only=名稱 只跑某幾項
npm run test:online    # 啟動真的伺服器，用 WebSocket 測房間、邀請、觀戰、斷線重連
npm run test:scroll    # Playwright：各尺寸各畫面的捲動檢查（頁面比視窗高就必須能捲）
npm run test:flow      # 流程卡死模糊測試：400 局隨機操作，任何時刻輪到的人都要有路可走
npm run test:stall     # Playwright 實機亂按：檢查按鈕是否灰掉、動畫是否卡住、電腦是否停住
npm run test:fuzz      # 深度規則模糊測試：所有道具／財神／蓋房詢問隨機打 300 局，檢查不變條件與「選單列出的動作一定能執行」
npm run test:online-items # 兩個真人瀏覽器連線對打、輪流用道具，並測對局中重新整理
npm run test:maps      # Playwright 實機：隨機地圖各開一局，檢查格數／3D 位置、用遙控骰走到每種格子後流程能繼續、商店買道具，並截圖
npm run test:items     # Playwright 實機：每種道具在各種落點使用後，都要能繼續擲骰／買地／結束回合
npm run test:browser   # Playwright：5 種視窗尺寸、設定彈窗、3D 棋盤、道具、單機一整局、線上流程
```

`test:browser` 需要 Playwright 與 Chromium（`npm i -g playwright`），無 GPU 的環境會用軟體 WebGL，比較慢；自動化瀏覽器（navigator.webdriver）會自動使用低畫質 3D（不影響版面），網址加 `?hq` 可關掉。

## 部署（免費方案）

專案已整理成可由 Git 平台匯入的狀態，推送與部署由你自行決定：

1. **伺服器**：Render 免費 Web Service（`render.yaml`）。Build 留空、Start 為 `node server.js`、健康檢查 `/health`。免費方案會休眠，第一位玩家進來要等 30～60 秒喚醒；房間只存在記憶體，服務重啟後未打完的對局會消失
2. **前端**（選用）：GitHub Pages（`.github/workflows/pages.yml`）。在 repo 的 Variables 設定 `GAME_SERVER_URL` 為伺服器網址，工作流程會在建置時執行 `node scripts/inject-server-url.js` 注入；正式建置請填公開網址
3. 伺服器 `GAME_ALLOWED_ORIGIN` 請填前端網址；正式環境使用 HTTPS／WSS
4. 想省事也可以只部署伺服器，它本身就會提供 `public/` 靜態檔案（同源，`GAME_SERVER_URL` 可省略）

## 假設與限制

- 「寶島一圈」40 格為接近經典版的台灣版配置
- 美術為程式繪製的向量圖與 3D 幾何，音效／音樂為程式合成，皆為暫用，可換成正式資產
- 邀請連結有房間範圍、有效期限，房主可撤銷；房間滿員時可選擇以觀戰身分加入
- 房間以實體玩家為準：只剩電腦或觀戰者時自動關閉，邀請連結失效，觀戰者會被送回大廳
- 需要支援 WebGL 的瀏覽器；戰績只記在本機

## 測試

- `node tests/verify.js`、`node tests/items.js`、`node scripts/online-check.js`、`node scripts/flow-fuzz.js`、`node scripts/deep-fuzz.js`：純規則測試，幾十秒跑完。
- `node scripts/run-e2e.js`：瀏覽器實機檢查（browser、shop、items、online-items、scroll、stall、maps 平行跑），約 8～9 分鐘；`--quick` 只跑主要三項。單項：`npm run test:shop` 等。
- 測試腳本共用 `scripts/_fast.js`（動作逾時 8 秒）和 `Solo.skipToMyRoll()`（快轉到輪到自己擲骰、不播中間動畫），避免卡在逾時與電腦回合上。
